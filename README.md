pirmiausiai atsisunciamas projakta su https://github.com/kornelijuspak/lapkricio-252.git

paleidus projakta instaliutis :

## .env

taip susikuriamas .env

.env yra klijojuojamas i backend

```
PORT=3000
MONGO_URI= retryWrites=true&w=majority
JWT_SECRET=
CLIENT_ORIGIN=http://localhost:5173
```

## backend

pirmiasiau nuiti i backend su

```
cd backend
```

instaliuoti su

```
npm i
```

atsidaryti terminala:

```
node server.js
```

## frontend

nueiti i frontend su

```
cd frontend
```

instaliuoti su

```
npm i
```

atsidaryti antra terminal :

```
npm run dev
```
